🔐 Authentication

POST /api/v1/auth/register Public
Register a new user
{
  "phone_number": "+251911234567",
  "password": "Test@123",
  "full_name": "Abebe Kebede",
  "role": "candidate" // or "boss"
}
POST /api/v1/auth/login Public
Login with phone number and password
{
  "phone_number": "+251911234567",
  "password": "Test@123"
}
GET /api/v1/auth/me Bearer Token
Get current user profile
Headers: Authorization: Bearer <token>

💼 Jobs

GET /api/v1/jobs Public
List all jobs with filters
Query Parameters:
  ?page=1&limit=10
  ?search=developer
  ?category=IT
  ?region=Addis Ababa
  ?job_type=Full-time
POST /api/v1/jobs Bearer Token (Employer)
Create a new job posting
{
  "title": "Software Developer",
  "description": "Job description here",
  "requirements": "Requirements here",
  "job_type": "Full-time",
  "category": "IT",
  "region": "Addis Ababa",
  "salary_min_etb": 30000,
  "salary_max_etb": 50000,
  "experience_level": "3-5 Years"
}
GET /api/v1/jobs/:id Public
Get job details by ID

📝 Applications

POST /api/v1/applications/:jobId/apply Bearer Token (Candidate)
Apply for a job
{
  "cover_letter": "I am interested in this position",
  "expected_salary": 40000
}
GET /api/v1/applications/my Bearer Token
Get user's applications

💬 Chat

GET /api/v1/chats/threads Bearer Token
Get chat threads
POST /api/v1/chats/threads Bearer Token
Start a new chat thread
{
  "jobId": "uuid-of-job"
}
GET /api/v1/chats/threads/:threadId/messages Bearer Token
Get messages in a thread

👤 Candidate Profiles

GET /api/v1/candidates/my-profile Bearer Token
Get candidate profile
PUT /api/v1/candidates/update-profile Bearer Token
Update candidate profile
{
  "profession_title": "Software Engineer",
  "years_of_experience": 5,
  "education_level": "Bachelor",
  "skills": ["JavaScript", "Node.js"],
  "summary": "Experienced developer"
}

📄 CV Generation

POST /api/v1/cv/generate Bearer Token
Generate PDF CV

🔔 Notifications

GET /api/v1/notifications Bearer Token
Get user notifications
GET /api/v1/notifications/unread-count Bearer Token
Get unread notification count
